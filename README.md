# Smelt — выпуски

Здесь лежат готовые сборки Smelt — приложения для диктовки на русском и
английском с сохранением технических терминов. Исходного кода в этом
репозитории нет, только выпуски.


## Скачать

Откройте [последний выпуск](https://github.com/alex-owen249/smelt-releases/releases/latest)
и скачайте файл для своей системы:

| Система | Файл |
|---|---|
| Windows 10/11 x64 | `Smelt-<версия>-windows-x64-portable.zip` |
| macOS, Apple Silicon | `Smelt-<версия>-macos-arm64.dmg` |

Рядом лежат `.sha256` (контрольная сумма) и `.sig` (подпись для
автообновления). Проверить скачанный файл:

```powershell
# Windows (PowerShell)
Get-FileHash .\Smelt-<версия>-windows-x64-portable.zip -Algorithm SHA256
```

```bash
# macOS
shasum -a 256 -c Smelt-<версия>-macos-arm64.sha256
```

## Установка

**Windows.** Распакуйте ZIP целиком в папку, где у вас есть права на запись,
например `C:\Apps\Smelt` или `%LOCALAPPDATA%\Programs\Smelt` (не в
`Program Files`), и запустите `Smelt.exe`. Сборка не подписана сертификатом
Microsoft, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить
в любом случае». Нужен Microsoft Edge WebView2 Runtime (в актуальных Windows
он уже есть).

**macOS.** Откройте `.dmg` и перетащите Smelt в «Программы». Сборка подписана
только ad-hoc, поэтому первый запуск надо разрешить: Системные настройки →
Конфиденциальность и безопасность → «Всё равно открыть». Для автовставки
выдайте Smelt доступ в «Универсальном доступе».

Модель распознавания (~1,6 ГБ) скачивается при первом выборе на странице
«Модели». Режим +LLM требует собственный ключ OpenRouter.

## Обновление

Smelt сам проверяет этот репозиторий при запуске и раз в сутки (можно
выключить в Настройках → «О программе»). Запрос анонимный: приложение
скачивает только файл `latest.json` последнего выпуска.

- **Windows:** «Обновить» в подвале боковой панели — Smelt скачает новую
  версию, проверит подпись автора и перезапустится. Прежняя версия остаётся
  рядом в папке `Smelt.old-<версия>`.
- **macOS:** «Скачать» откроет новый `.dmg`; замените Smelt в «Программах».

Настройки, история и ключ OpenRouter хранятся в профиле пользователя и при
обновлении не теряются.

## Что внутри пакета

Оболочка приложения (Rust/Tauri) и интерфейс поставляются в скомпилированном
виде. Голосовой движок — встроенный Python 3.12 с библиотеками и исходными
файлами движка. Ваши записи и тексты никуда не отправляются, кроме
облачной LLM в режиме +LLM (OpenRouter, с вашим ключом).
